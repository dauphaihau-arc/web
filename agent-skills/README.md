# Web Agent Skills

Focused instructions for coding agents working in the Nuxt web monorepo.

Read this index first, then load only the files relevant to the task.

- `src-structure.md` - source ownership and placement rules for seller, storefront, and shared packages
- `domain-boundaries.md` - domain module and shared package dependency rules
- `ui-conventions.md` - UI implementation conventions for Arc web apps
- `testing.md` - how to verify behavior changes and where to add tests
- `thin-pages.md` - keep Nuxt page files focused on route ownership and page composition
- `clean-vue-components.md` - split complex Vue components into local composables, constants, and support modules
- `vue-props-reactivity.md` - preserve prop reactivity when using `defineProps`
